Prompt Kit pour Claude Code

Décris ce que tu veux faire en français normal. On te donne le bon prompt, le bon modèle et le kit mémoire à coller dans Claude Code.

Étape 1 / 4

1. Qu'est-ce que tu veux faire ?

Décris-le comme si tu parlais à un ami. Pas besoin de jargon technique.

Panne d'inspiration ? Clique sur un exemple pour démarrer :

2. Quel type de tâche ?

Choisis ce qui correspond le mieux.

3. Quelle ampleur ?

Sers-toi de ton intuition, ce n'est pas une science exacte.

4. Contexte (optionnel)

Ajoute tout ce qui peut aider : technos que tu connais ou préfères, contraintes, ce que tu as déjà essayé.

Ton kit Claude Code est prêt

Suis les étapes dans l'ordre. Chaque bloc se copie en un clic.
